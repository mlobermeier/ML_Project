Goal of this project is to build a predictive model that estimates listing prices for Airbnb accommodations in Dublin Ireland.
https://pad.gwdg.de/s/FXe6pqC1p#
---------------------------------------------

Can be used in linux terminal with "python run_airbnb.py"
Can otherwise be executed from notebooks/runner_notebook.ipynb
---------------------------------------------
This project requires Python 3.13.3+.
Other versions may work, but are not guaranteed to be compatible.

--------------------------------------------
All dependencies are listed in requirements. txt. You can install them using:

pip install -r requirements.txt

If you don’t already have a virtual environment, you can set one up like this:

python -m venv venv
source venv/bin/activate    # On Windows: venv\Scripts\activate
pip install -r requirements.txt
