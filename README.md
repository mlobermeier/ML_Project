### Airbnb Price Prediction - Dublin, Ireland

Goal of this project is to build a predictive model that estimates listing prices for Airbnb accommodations in **Dublin Ireland**.
https://pad.gwdg.de/s/FXe6pqC1p#

---

Can be executed from terminal with:
python run_airbnb.py
Can otherwise be executed by opening and running notebooks/runner_notebook.ipynb

---

This project requires Python 3.13+.
Other versions may work, but are not guaranteed to be compatible.

---

All dependencies are listed in requirements. txt. You can install them using:

pip install -r requirements.txt

A virtual environment is recommended, you can set one up like this:

python -m venv venv
source venv/bin/activate    # On Windows: venv\Scripts\activate
pip install -r requirements.txt
